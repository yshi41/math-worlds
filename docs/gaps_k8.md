# Grades 1–8 Common Core gaps

The game-able grade 2–8 standards (CCSS-M) that no concept practises yet, each with a proposed new concept, then the
standards that are only partly covered and should get one. Standards, alignment and regrades are in
`src/concepts/z_ccss_k8.js` (grade 1 is listed there as review and is left out here).

Columns: id, strand, grade, title, the typed-answer problems, standard, ✎ = `paper: true`.
Answer types: numbers, fractions, money, time, quotient-remainder.
